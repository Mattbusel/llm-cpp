# Security policy

## Supported versions

Fixes go into the latest 1.x release of llm-cpp and into the library's own
repository (`Mattbusel/llm-<name>`). Older releases are not patched; update to
the latest 1.x, which keeps the same API.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/Mattbusel/llm-cpp/security/advisories/new).
That reaches the maintainer only. Include the header, the version
(`LLM_CPP_VERSION`) and a way to reproduce it.

Once a fix is released, the advisory is published with credit to you unless
you ask otherwise.
